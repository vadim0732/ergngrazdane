# Требования из КОД 09.02.07-3-2026 Том 1 → демо «гражданам.егрн»

Источник: `/workspace/КОД 09.02.07-3-2026 Том 1.pdf` (текст: `_pdf_extract/full_text.txt`).

## Важно про предметную область

В PDF **единственная** предметная область образца задания — портал **«Корочки.есть»** (запись на курсы ДПО).  
Строк «гражданам.егрн» / ЕГРН в PDF **нет**.

Пробное демо DEMOWEB использует бренд **гражданам.егрн** как параллельную учебную тему с **той же функциональной сеткой** модулей 1–3. Ниже — требования PDF и явный маппинг.

## Уровни и модули (PDF)

| Аттестация | Модули | Время | Макс. балл |
|------------|--------|-------|------------|
| ПА | М1 | 1 ч 30 мин | 25 |
| ГИА ДЭ БУ | М1+М2 | 3 ч | 50 |
| ГИА ДЭ ПУ (инвариант) | М1+М2+М3 | 4 ч | 75 |

### Модуль 1 — Проектирование и разработка ИС
- Спроектировать БД + **ER средствами СУБД**
- Полный стек: фронт + бек + БД + ООП + библиотеки/фреймворки
- Коммиты в начале и конце модуля
- Экраны: регистрация, авторизация, просмотр заявок (+ отзыв), формирование заявки, админ-панель

### Модуль 2 — Разработка дизайна веб-приложений
- Оптимизация медиа из приложения к заданию
- Мобильные макеты **390×844** (отдельный HTML на экран)
- Слайдер: **4** одинаковых по размеру кадра, автосмена **3 с**, вперёд/назад
- Усиления: ошибки валидации на форме; отзыв только после завершения; курс из **select**; дата **ДД.ММ.ГГГГ**; админ — фильтр / toast / пагинация

### Модуль 3 — Проектирование, разработка и оптимизация
- Доработка БД под все задачи М1+М2
- Адаптив, качество кода
- Анимации / микроанимации для UX
