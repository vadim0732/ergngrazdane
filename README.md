# Портал «гражданам.егрн» — пробное демо по КОД 09.02.07-3-2026

Комплект собран по **функциональным требованиям** PDF  
`КОД 09.02.07-3-2026 Том 1.pdf` (модули 1–3: БД/ER, экраны, дизайн, слайдер, mobile 390×844, оптимизация).

> В образце задания PDF предметная область — **«Корочки.есть»**.  
> Здесь та же сетка требований с тематическим маппингом на **гражданам.егрн**  
> (см. `docs/requirements-from-pdf.md`). Это не «просто перекраска korochki»: источник — PDF.

## Запуск

```bash
cd grazhdanam-egrn
pip install -r requirements.txt
python app.py
```

http://127.0.0.1:5001 · Windows: `run.bat`

| Роль | Логин | Пароль |
|------|-------|--------|
| Админ | `Admin` | `EgrnNET` (в PDF: `KorokNET`) |
| Пользователь | регистрация | ≥ 8 символов |
